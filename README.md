# Desarrollo de aplicaciones para ambientes Web Avanzado

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Desarrollo de aplicaciones para ambientes Web Avanzado**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!

Durante los laboratorios construirás progresivamente **TaskFlow**, una aplicación de gestión de tareas con PHP, Laravel, MySQL, Blade, Tailwind CSS y JavaScript. Cada laboratorio parte del resultado del anterior, por lo que deben realizarse en orden.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### [Práctica 1. Fundamentos de Laravel y desarrollo full-stack](Capitulo01/README.md)

  - **Descripción**: Construir una primera versión funcional de TaskFlow con rutas, controlador, vistas y componentes Blade reutilizables y estilos de Tailwind CSS mediante Vite.

  - ⏱️ **Duración estimada**: 180 min.

### [Práctica 2. CRUD full-stack con Laravel y MySQL](Capitulo02/README.md)

  - **Descripción**: Convertir TaskFlow en una aplicación CRUD persistente con MySQL, con categorías, validaciones, ordenamiento y paginación.

  - ⏱️ **Duración estimada**: 180 min.

### [Práctica 3. Autenticación básica y roles en TaskFlow](Capitulo03/README.md)

  - **Descripción**: Registrar usuarios, iniciar y cerrar sesión, proteger el CRUD y distinguir los roles `user` y `admin` con una pantalla administrativa.

  - ⏱️ **Duración estimada**: 180 min.

### [Práctica 4. Seguridad web esencial en TaskFlow](Capitulo04/README.md)

  - **Descripción**: Reforzar TaskFlow con validación en el backend, protección CSRF y XSS, verificación de hashing y adjuntos privados con carga, descarga y eliminación controladas.

  - ⏱️ **Duración estimada**: 180 min.

### [Práctica 5. Desarrollo y consumo de APIs REST con TaskFlow](Capitulo05/README.md)

  - **Descripción**: Crear una API REST autenticada con Laravel Sanctum y consumirla desde Blade mediante `fetch()` sin recargar la página.

  - ⏱️ **Duración estimada**: 210 min.

### [Práctica 6. Integración full-stack con Blade, Vite e introducción a Inertia](Capitulo06/README.md)

  - **Descripción**: Integrar Laravel, Eloquent, Blade, Vite y JavaScript con filtros instantáneos y estadísticas calculadas en el backend, y contrastar Blade, Inertia y API.

  - ⏱️ **Duración estimada**: 150 min.
