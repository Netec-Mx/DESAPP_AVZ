# Desarrollo de aplicaciones para ambientes Web Avanzado

**Clave del curso:** DESAPP_AVZ  
**Duración:** 40 horas

## Descripción

Este curso introduce al participante al desarrollo de aplicaciones
web full-stack utilizando PHP, Laravel, MySQL, Blade, Tailwind CSS
y JavaScript.

Durante los laboratorios se construirá progresivamente TaskFlow,
una aplicación de gestión de tareas que permitirá aplicar los
conocimientos adquiridos en cada capítulo.

El curso culmina con un proyecto final integrador.

## Preparación del entorno

Antes de comenzar, consultar la guía de preparación del ambiente:

- [Setup Guide](./SETUP_GUIDE.md)

## Consideraciones

- Los laboratorios deben realizarse en orden consecutivo.
- TaskFlow es un proyecto acumulativo.
- Cada laboratorio utiliza los resultados del anterior.
- No eliminar el proyecto ni la base de datos entre prácticas.
- El capítulo 7 contempla contenido y demostraciones de IA,
  sin un laboratorio independiente.

## Proyecto final

Durante el capítulo 8, el participante desarrollará una
aplicación full-stack de manera autónoma, aplicando los
conocimientos adquiridos durante el curso.

El instructor proporcionará los requerimientos y criterios
de aceptación correspondientes.
